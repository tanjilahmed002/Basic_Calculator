# 🧮 Python Calculator

A simple command-line calculator built with Python.

This project is created to practice **Python Functions, Modules, User Input, Conditional Statements, and While Loops**.

---

## 📌 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- `%` Modulus
- 🔢 Power
- 🚪 Exit option
- 🔄 Continuous calculation using a while loop
- 📁 Functions are separated into a different Python file

---

## 🛠️ Technologies Used

- Python 3
- Python Functions
- Python Modules
- While Loop
- If-Else Statements
- User Input
